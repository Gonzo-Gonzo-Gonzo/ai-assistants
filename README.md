# AI Assistants

Teams configuring assistants need to know which tasks they can handle, which tools they may use, and when a person should review the result. This example describes how a team prepares an assistant for a routine internal task.

## Objectives

- Define the questions the assistant should handle.
- Give the assistant access to the information and tools needed for those questions.
- Evaluate answers and route uncertain cases to a person.

## Representative workflow

A support lead configures an assistant to answer common policy questions from approved documentation. They test it on representative questions and check that its answers agree with the source material. When a question falls outside the documented policy, the assistant routes it for human review.
